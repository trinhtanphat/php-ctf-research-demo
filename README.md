# PHP CTF Research Lab — Unofficial Static Demo

Standalone public frontend companion to a **private** research repository. This is not Cloudflare or an official CTF. All controls are offline only, and it has no RCE endpoints, flag verification, or network calls to the challenge.

Official challenge: https://php-rce.cloudflare.app/

All frontend files live at the repo root for GitHub Pages branch deployment. No PHP backend or exploit payloads are hosted.
